# 🏷️ Options de nommage pour la solution Blender MCP

## Contexte
Cette solution permet de :
- Créer des instances Blender multiples via web
- Exposer une API MCP pour assistants IA
- Gérer un grid/réseau d'instances Blender
- Fournir une interface web de gestion

## Options de noms

### 1. **BlenderGrid MCP** ⭐ **(Recommandé)**
- **Concept** : Grille de calcul d'instances Blender
- **Usage** : `blender-grid-mcp`, `BlenderGrid MCP Service`
- **Avantages** : Évoque le calcul distribué, distinctif, technique
- **URL** : `blendergrid.io`

### 2. **BlenderHub MCP**
- **Concept** : Hub central pour gérer les instances
- **Usage** : `blender-hub-mcp`, `BlenderHub`
- **Avantages** : Simple, évoque la centralisation
- **URL** : `blenderhub.io`

### 3. **BlenderCanvas**
- **Concept** : Canvas artistique partagé
- **Usage** : `blender-canvas`, `BlenderCanvas MCP`
- **Avantages** : Métaphore créative, évoque l'espace partagé
- **URL** : `blendercanvas.io`

### 4. **BlenderStudio MCP**
- **Concept** : Studio de production multi-projets
- **Usage** : `blender-studio-mcp`
- **Avantages** : Professionnel, environnement collaboratif
- **URL** : `blenderstudio.io`

### 5. **BlenderLab**
- **Concept** : Laboratoire d'expérimentation IA
- **Usage** : `blender-lab`, `BlenderLab MCP`
- **Avantages** : R&D, innovation, IA
- **URL** : `blenderlab.io`

### 6. **BlenderMesh**
- **Concept** : Réseau maillé d'instances
- **Usage** : `blender-mesh-mcp`
- **Avantages** : Référence 3D + réseau
- **URL** : `blendermesh.io`

### 7. **BlenderOrchestra**
- **Concept** : Orchestration d'instances
- **Usage** : `blender-orchestra`
- **Avantages** : Coordination, harmonie
- **URL** : `blenderorchestra.io`

### 8. **BlenderServe**
- **Concept** : Service web Blender
- **Usage** : `blender-serve`
- **Avantages** : Simple, explicite
- **URL** : `blenderserve.io`

## Structure de nommage complète (exemple avec BlenderGrid)

```yaml
# Identité
nom_court: "BlenderGrid"
nom_complet: "BlenderGrid MCP Service"
tagline: "Grille d'instances Blender pour assistants IA"

# Technique
nom_package: "blender-grid-mcp"
docker_image: "blender-grid:latest"
repository: "blender-grid-mcp"

# URLs
domain: "blendergrid.io"
api_endpoint: "api.blendergrid.io"
docs: "docs.blendergrid.io"

# Branding
logo: "🎨🔗" # Blender + Grid
couleurs: 
  primary: "#007acc" # Bleu Blender
  secondary: "#ff6b35" # Orange accent
```

## Différenciation

| Nom | vs Blender | vs MCP Blender | Notre valeur unique |
|-----|------------|----------------|---------------------|
| BlenderGrid | Grid = multi-instances | Grid = infrastructure | Grille de calcul web |
| BlenderHub | Hub = centralisation | Hub = point d'accès | Gestionnaire central |
| BlenderCanvas | Canvas = web/partage | Canvas = créatif | Espace collaboratif |
| BlenderStudio | Studio = pro | Studio = workflow | Environnement complet |

- Évolutivité
- Différenciation claire
- Mémorabilité
- Adéquation avec la fonctionnalité
