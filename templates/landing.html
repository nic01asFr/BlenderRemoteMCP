BlenderRemoteMCP

Blender 4.0 dans le cloud, piloté par un agent via le Model Context Protocol. Bureau live dans le navigateur, outils scène / matériaux / rendu, déployable sur SSPCloud.

Ouvrir le bureau Santé Endpoint MCP

Connexion MCP

{
  "mcpServers": {
    "blender": {
      "url": "{{ public_base }}/mcp",
      "transport": "streamable-http",
      "headers": {
        "Authorization": "Bearer blender_…"
      }
    }
  }
}

À savoir

  • get_canvas_url — lien du bureau à donner à l’utilisateur
  • blender_desktop_ui — vue inline (MCP Apps) si le client la supporte
  • get_screenshot — capture X11 du viewport live
  • Auth : Bearer blender_… ou OAuth MCP (Claude Desktop / connecteur distant)
  • Découverte : /.well-known/oauth-protected-resource
